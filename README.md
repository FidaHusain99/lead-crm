## Tech Stack
- Next.js, React, Tailwind CSS
- Prisma ORM, MySQL (TiDB Cloud)
- NextAuth for Authentication
- Deployed on Render

## Features
- Admin Login
- Lead Management (Add, Edit, Delete, Status Update)
- Follow-up System
- Dashboard

## How to run locally
npm install
npm run dev

## DB Structure
- User Table (Admin login)
- Lead Table (name, email, phone, status)
- FollowUp Table (leadId, notes, date)

## Deployment
Deployed on Render with Auto-Deploy enabled from GitHub.
